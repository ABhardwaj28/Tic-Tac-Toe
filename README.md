# 🎮 Tic Tac Toe

A modern, responsive, and interactive Tic Tac Toe web game built with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- **Complete Win Detection**: Accurately detects row, column, and diagonal wins.
- **Draw / Tie Detection**: Handles board fill ties gracefully.
- **Scoreboard Tracking**: Real-time score tracker for Player O, Player X, and Ties across rounds.
- **Visual Turn & Win Feedback**: Clear turn indicators and celebratory winning line animations.
- **Instant Restart**: Quick "Restart Game" button to replay rounds without page reloads.
- **Responsive & Modern UI**: Sleek dark-mode aesthetic with fluid layout optimized for both desktop and mobile devices.

## 🚀 How to Run
Simply open `index.html` in any modern web browser:
- Double click `index.html`, or
- Serve it locally with any static server:
  ```bash
  # Python 3
  python3 -m http.server 8000
  ```
  Then navigate to `http://localhost:8000`.

## 🛠️ Tech Stack
- HTML5
- CSS3 (CSS Grid & Flexbox, Custom Properties, Keyframe Animations)
- Vanilla JavaScript (ES6+)
